## 작업: [대상파일] [N]개 [필드명] 일괄 수정

### 1. 파일 목록

| 동작 | 경로 | 역할 |
|------|------|------|
| 수정 | [glob 패턴, 예: apps/*/gujo-product.json] | [필드] 값 변경 |

### 2. 스펙

분류/변환 규칙:
- [조건 1] → [값 1]
- [조건 2] → [값 2]
- [조건 N] → [값 N]
- 나머지 → [기본값]

조건 판별 기준: [어떤 필드를 보고 판단하는지]

### 3. 제약

- JSON indent 2, ensure_ascii=False, 파일 끝 개행 1개
- [대상 블록] 없는 파일은 건드리지 않음
- [대상 필드] 외 다른 필드 변경 금지
- Python3 스크립트로 일괄 처리 (파일별 수동 수정 금지)

### 4. 하지 말 것

- 분류 규칙 자의적 변경/추가
- 새 카테고리·값 발명
- [대상 블록] 신규 생성
