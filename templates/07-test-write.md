## 작업: [모듈명] 유닛 테스트 [N]건 작성

### 1. 파일 목록

| 동작 | 경로 | 역할 |
|------|------|------|
| 생성 | Tests/[모듈]Tests/[Class]Tests.swift | [대상] 테스트 |

### 2. 스펙

테스트 케이스:

| # | 메서드 | 입력 | 기대 결과 |
|---|--------|------|---------|
| 1 | test_[동사]_[조건]_[결과] | [구체적 입력] | [구체적 출력] |
| 2 | test_[동사]_[조건]_[결과] | [구체적 입력] | [구체적 출력] |
| N | test_[에러케이스] | [비정상 입력] | [에러/폴백] |

### 3. 제약

- XCTest 프레임워크
- async/await 테스트는 XCTestExpectation 또는 async test
- Mock: [CommandRunning 등] 프로토콜 기반 주입
- 파일 I/O 테스트: 임시 디렉토리 사용 + tearDown 정리

### 4. 하지 말 것

- 프로덕션 코드 수정
- 외부 네트워크 호출
- 테스트 간 상태 공유
- sleep/delay 기반 동기화
